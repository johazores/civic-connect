# Changelog

Notable project and repository changes are documented here.

## Unreleased

### Added

- MIT licensing and public contribution, security, roadmap, conduct, demo, metadata, and documentation index files.

### Changed

- Reorganized the public README around the current product rather than internal implementation history.
- Moved demo credentials and setup details into dedicated documentation.
- Clarified Stellar modules as testnet proof-of-payment and public-record prototypes.

## Current platform milestone

### Added

- Multi-tenant citizen and staff portals.
- Citizen reports, tracking, services, news, and emergency hotline modules.
- Staff queues, departments, categories, content management, and user management.
- PostgreSQL and Prisma data layer.
- PWA application shell and mobile navigation.
- Tenant Stellar testnet wallet management.
- SEP-7 payment intents, QR codes, Horizon verification, and public receipts.
- Civic participation, environmental, transparency, and tax-receipt prototype modules.

### Limitations

- Stellar modules use testnet only.
- Seeded credentials are development-only.
- Clerk migration is planned but not active.
- Production government deployment requires security, privacy, accessibility, operational, and legal review.
